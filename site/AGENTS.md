## Architecture rules

- Prefer native browser/platform capabilities and existing VDS9 modules before adding dependencies.
- Keep primary content semantic and available without JavaScript. JavaScript progressively enhances.
- Do not silently change canonical URLs, indexability, hreflang, structured-data identity or established redirect/retirement plans.
- Do not bypass Search, GEO, accessibility, Agentic Browsing, security or performance gates to make a test pass.
- Treat `automationEligible` as evidence classification, never as permission to mutate or deploy.
- Never commit credentials, API keys or tokens. DeepSeek credentials remain in the user's Kilo/provider configuration or local environment.
